# Product Mission (Lite)

Tower Defense Learning Game is a Roblox educational game that helps aspiring game developers master AI programming and iterative development by providing a hands-on tower defense implementation with comprehensive pathfinding, decision trees, and state machines.

Tower Defense Learning Game serves game development students and AI programming enthusiasts who need practical experience with sophisticated game systems. Unlike typical educational resources that teach concepts in isolation, this project demonstrates integrated AI systems working together in a complete, playable experience with modular architecture designed specifically for learning and incremental development.
